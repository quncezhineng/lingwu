# D1 + D2 UI 规格文档 — 观察列表 & 市场简报卡片

> 作者：UI 设计师 | 版本：1.0 | 日期：2026-10-26
> 基于 LingWu 现有设计系统（border-first, purple brand #4B3FE3, radius 999/14/10）

---

## 一、设计原则

- **一致性**：复用现有 `Card`、`Button`、`Chip`、`Sheet`、`Empty`、`SectionHeading` 等组件
- **border-first**：1px `line`(#E7EAEF) 边框，不使用阴影
- **surface ladder**：canvas(#FFFFFF) → surface(#EFF1F4) → tertiary(#E7EAEF)
- **品牌色**：primary #4B3FE3，sky #E5EAFF 用于品牌浅底
- **行情语义色**：涨 #E8463A（红），跌 #15A877（绿），平 #737373
- **radius 系统**：999（capsule）、14（卡片）、10（控件/输入框）
- **响应式**：移动端（<600）单列，平板/桌面（≥600）双栏，宽屏（≥900）三栏

## 七、无障碍（Accessibility）

| 要求         | 实现                                                                          |
| ------------ | ----------------------------------------------------------------------------- |
| 涨跌幅对比度 | 红 #E8463A / 绿 #15A877 在白色背景上均 ≥ 4.5:1（WCAG AA）                     |
| 图标+文本    | 所有图标旁必须有文本标签（涨跌用 ▲▼ + 百分比数字）                            |
| 触摸目标     | 所有可点击区域 ≥ 44x44px                                                      |
| 屏幕阅读器   | 标的卡片 accessibilityLabel: "AAPL Apple Inc, 最新价 198.50 美元, 日涨 2.34%" |
| 动画减少     | 尊重 prefers-reduced-motion，禁用 shimmer 和展开动画                          |
| 字体缩放     | 支持 Dynamic Type，布局不错乱                                                 |
