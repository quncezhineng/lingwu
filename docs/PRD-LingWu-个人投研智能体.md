# PRD: LingWu 个人投研智能体

> 版本：v1.0 | 日期：2026-10-24 | 作者：产品经理 | 状态：Draft

---

## 1. Summary

LingWu 当前是一个通用个人智能体平台，具备持久化浏览器、Linux 沙箱、耐久任务引擎、AG-UI 流式对话、邮件/日历/搜索/PDF/金融导入等基础能力。本 PRD 描述在现有架构上改造为**个人投研智能体**的产品方案，核心目标是让个人投资者拥有一个能自动抓取行情与资讯、深度研究标的、管理投资组合、持续监控并推送异动的 AI 投研助手。

本版本聚焦 **P0 功能**（每日市场简报、观察列表与标的动态、深度研究任务），同时为 P1/P2 功能预留架构扩展点。

## 2. Background and Evidence

### 2.1 背景

- 个人投资者面临信息过载：行情、新闻、公告、研报、社交媒体信号分散在数十个渠道，手动跟踪成本极高。
- 现有投研工具（Wind、Bloomberg Terminal、东方财富 Choice）面向机构，价格高、学习曲线陡峭，不适合个人用户。
- AI Agent 技术成熟度已达到可自动化完成"信息收集→分析→摘要→监控"全链路的水平。

### 2.2 目标用户

| 用户画像            | 描述                 | 核心诉求                       |
| ------------------- | -------------------- | ------------------------------ |
| **价值投资者**      | 长期持有、关注基本面 | 深度研究、财报分析、估值模型   |
| **趋势交易者**      | 关注技术面和市场情绪 | 实时行情、技术指标、舆情监控   |
| **基金/ETF 投资者** | 资产配置导向         | 组合管理、再平衡建议、绩效归因 |
| **研究型投资者**    | 喜欢记录和复盘       | 投资笔记、决策日志、知识库     |

### 2.3 现有能力复用分析

| 现有能力       | 投研场景复用方式                       |
| -------------- | -------------------------------------- |
| 持久化浏览器   | 自动抓取行情、新闻、公告、社交舆情     |
| Linux 沙箱     | 运行 Python 做数据分析、估值建模、回测 |
| 耐久任务引擎   | 定时执行市场简报、监控任务、财报抓取   |
| PDF 管线       | 解析研报 PDF、财报 PDF，提取关键数据   |
| AG-UI 流式对话 | 交互式研究问答、研报生成过程实时展示   |
| Finance 卡片   | 扩展为行情卡片、组合卡片               |
| Goals 监控     | 扩展为价格提醒、舆情异动提醒           |
| Web Search     | 财经新闻搜索、公告搜索                 |

## 3. Goal and Success Criteria

### 3.1 产品目标

让个人投资者在 LingWu 中获得**一站式 AI 投研体验**：从信息获取、标的研究、组合管理到持续监控，全部由 Agent 自动化或辅助完成。

### 3.2 成功标准

| 指标                       | 目标值    | 衡量方式            |
| -------------------------- | --------- | ------------------- |
| 每日市场简报生成成功率     | ≥ 99%     | 耐久任务执行日志    |
| 深度研究任务平均完成时间   | ≤ 5 分钟  | Agent 任务计时      |
| 用户周活跃使用天数         | ≥ 4 天    | 用户行为埋点        |
| 观察列表标的动态推送准确率 | ≥ 95%     | 推送日志 + 用户反馈 |
| 用户对 AI 研报质量满意度   | ≥ 4.0/5.0 | 应用内评分          |

## 4. Users and Scenarios

### 4.1 核心场景

**场景 1：晨间市场简报**

- 用户早上打开 LingWu，看到 Agent 已生成的今日市场简报
- 简报包含：隔夜美股/欧股/亚太收盘、持仓标的动态、今日关注事件（财报发布、经济数据）
- 用户可追问"详细说说宁德时代最近的财报"

**场景 2：深度研究一只股票**

- 用户说"帮我研究一下比亚迪"
- Agent 自动执行：拉取最新财报数据 → 计算关键指标（PE/PB/ROE/营收增速）→ 搜索近期新闻和研报 → 对比同业（特斯拉、蔚来、理想）→ 生成结构化研报
- 研报以 PDF 或内联卡片形式展示，用户可下载或加入知识库

**场景 3：观察列表监控**

- 用户维护一个观察列表（如：AAPL, TSLA, 宁德时代, 贵州茅台）
- Agent 每日自动扫描列表中标的的异动：价格突破关键位、重大新闻、公告发布、舆情突变
- 异动通过推送通知用户，用户可一键查看 Agent 生成的异动分析

**场景 4：投资组合管理**

- 用户导入持仓（CSV 或手动输入）
- Agent 自动计算：资产配置分布、行业集中度、年化收益、与基准对比、Sharpe/MaxDD
- 用户问"我的组合风险暴露怎么样"，Agent 给出分析和建议

**场景 5：投资笔记与复盘**

- 用户买入某只股票时，记录买入理由和论点
- Agent 定期（如每周）自动检验论点是否仍成立，给出提示
- 季度末 Agent 自动生成投资组合复盘报告

## 5. Scope

### 5.1 In Scope（本版本）

| 模块             | 功能                                          | 优先级 |
| ---------------- | --------------------------------------------- | ------ |
| **每日市场简报** | 自动生成隔夜市场回顾、持仓动态、今日事件      | P0     |
| **观察列表**     | 创建/管理关注标的分组，Agent 定期生成摘要     | P0     |
| **标的动态推送** | 价格异动、重大新闻、公告事件提醒              | P0     |
| **深度研究任务** | 单标的全面研究：财报+新闻+同业+估值，输出研报 | P0     |
| **持仓导入**     | CSV 导入 + 手动录入                           | P1     |
| **组合分析面板** | 资产配置、风险指标、收益对比基准              | P1     |
| **投资笔记**     | 记录买入理由、论点追踪                        | P1     |
| **财报自动解析** | 财报 PDF 解析关键数据、与预期对比             | P1     |
| **行情卡片**     | 内联展示实时报价、涨跌幅、成交量              | P1     |

### 5.2 Out of Scope（后续版本）

| 功能                                | 原因                         |
| ----------------------------------- | ---------------------------- |
| 社交舆情监控（Reddit/雪球情绪分析） | 数据源接入复杂度高，P2       |
| 选股筛选器（自然语言条件筛选）      | 需要结构化金融数据库支撑，P2 |
| 策略回测                            | 需要历史行情数据库，P2       |
| 投资知识库沉淀与检索                | 依赖向量数据库，P2           |
| 研报分享 / 投资俱乐部               | 社交功能，非核心投研链路，P2 |
| 券商 API 直连同步持仓               | 涉及第三方授权和合规，P2     |
| 技术图表（K线、MACD 等）            | 需要前端图表库集成，P2       |

### 5.3 Non-Goals

- **不提供投资建议**：Agent 输出均为信息整理和分析辅助，不构成买卖建议，需在 UI 上明确声明。
- **不替代专业投研终端**：不追求 Wind/Bloomberg 级别的数据完整性和实时性。
- **不做交易执行**：不涉及任何买入/卖出下单操作。
- **不做社交/社区**：本版本不包含用户间互动功能。

## 7. User Flow

### 7.1 每日市场简报流程

```
用户打开 LingWu
  → 首页展示"今日市场简报"卡片（由耐久任务每日定时生成）
  → 卡片摘要：3-5 条核心要点
  → 点击展开完整简报
  → 可追问："详细说说 XX" → 进入对话式研究
```

### 7.2 深度研究流程

```
用户在对话中输入"研究一下 [标的名称/代码]"
  → Agent 确认标的（如有歧义，列出候选）
  → Agent 展示研究计划（步骤列表）
  → Agent 依次执行：
    1. 拉取最新行情数据 → 展示行情卡片
    2. 搜索近期新闻和公告 → 展示新闻列表
    3. 解析最近财报 PDF → 展示关键指标
    4. 对比同业公司 → 展示对比表
    5. 生成估值分析（DCF/相对估值）→ 展示估值区间
  → Agent 汇总为结构化研报
  → 用户可：下载 PDF / 保存到知识库 / 追问细节
```

### 7.3 观察列表管理流程

```
用户进入"观察列表"页面
  → 创建列表（如"新能源"、"消费龙头"）
  → 添加标的（输入代码或名称，Agent 自动匹配）
  → 每个标的展示：最新价、涨跌幅、近期异动标记
  → 点击标的 → 进入标的详情页（行情+新闻+公告+Agent 分析）
  → Agent 每日定时扫描列表，生成异动摘要并推送
```

### 7.4 持仓管理流程

```
用户进入"投资组合"页面
  → 创建组合（如"长期价值"）
  → 导入持仓：CSV 上传 或 手动逐条录入
  → Agent 自动匹配标的并计算：
    - 当前市值、成本、盈亏
    - 资产配置分布（饼图）
    - 行业集中度
    - 年化收益率 vs 基准
  → 用户可查看组合健康度报告
  → 用户可手动调整持仓或标记已卖出
```

### 7.5 投资笔记流程

```
用户在标的详情页或对话中记录笔记
  → 笔记类型：买入理由、卖出理由、研究心得、论点
  → 笔记自动关联到标的
  → Agent 定期（每周）检验论点是否仍成立
  → 用户可查看"论点追踪"面板：所有活跃论点及其状态
```

## 8. Functional Requirements

### R1: 每日市场简报

- **用户故事**：作为投资者，我希望每天早上打开 LingWu 就能看到今日市场简报，了解隔夜市场动态和我关注的标的变化。
- **功能行为**：
  - 耐久任务每日 UTC 00:00（可配置）自动触发
  - 抓取隔夜主要市场（美股、欧股、亚太）收盘数据
  - 扫描用户观察列表和持仓标的的近期动态
  - 汇总今日重要事件（财报发布、经济数据、央行会议）
  - 生成 3-5 条核心要点 + 完整简报正文
  - 简报以卡片形式展示在首页，支持展开和追问
- **数据需求**：
  - 市场指数数据（收盘价、涨跌幅）
  - 用户观察列表和持仓数据
  - 财经新闻和事件日历
- **验收标准**：
  - 简报在用户首次打开应用时已生成（≤ 用户所在时区 08:00）
  - 要点数量 3-5 条，每条 ≤ 50 字
  - 追问后 Agent 能基于简报内容继续展开分析
  - 生成失败时有降级提示（如"今日简报生成失败，请手动刷新"）

### R2: 观察列表

- **用户故事**：作为投资者，我希望管理多个观察列表，跟踪我关注的标的，并定期收到 Agent 生成的摘要。
- **功能行为**：
  - 支持创建多个列表（分组管理）
  - 添加标的：输入代码或名称，Agent 自动匹配（支持 A 股、港股、美股、ETF、基金）
  - 每个标的展示：最新价、日涨跌幅、周涨跌幅、近期异动标记
  - Agent 每日定时扫描列表，生成异动摘要
  - 点击标的进入详情页
- **数据需求**：
  - 标的元数据（代码、名称、市场、行业）
  - 行情数据（价格、涨跌幅、成交量）
  - 异动检测逻辑（价格突破、成交量异常、重大新闻）
- **验收标准**：
  - 列表创建/删除/重命名操作即时生效
  - 标的添加后 ≤ 1 分钟展示最新行情
  - 每日摘要在用户打开应用前生成
  - 支持至少 100 个标的/列表

### R3: 标的动态推送

- **用户故事**：作为投资者，我希望在我关注的标的出现重大异动时及时收到通知。
- **功能行为**：
  - 监控维度：价格异动（涨跌幅超阈值）、重大新闻、公告发布、舆情突变
  - 用户可配置每个标的的推送阈值（如涨跌幅 > 5%）
  - 推送内容：标的名称 + 异动类型 + 简要描述 + 一键查看详情
  - 详情页展示 Agent 生成的异动分析
- **数据需求**：
  - 实时行情数据（或 15 分钟延迟）
  - 新闻和公告数据源
  - 用户推送偏好配置
- **验收标准**：
  - 价格异动推送延迟 ≤ 15 分钟（受行情数据延迟限制）
  - 推送准确率 ≥ 95%（误报率 ≤ 5%）
  - 用户可一键关闭某标的的推送
  - 推送去重：同一异动 24 小时内不重复推送

### R4: 深度研究任务

- **用户故事**：作为投资者，我希望输入一个标的名称，Agent 自动完成全面研究并输出结构化研报。
- **功能行为**：
  - 用户输入标的名称或代码
  - Agent 展示研究计划（步骤列表），用户可调整
  - Agent 依次执行：
    1. 公司概况（主营业务、行业地位、竞争优势）
    2. 财务分析（近 3 年营收/利润/现金流、关键比率）
    3. 近期新闻和公告汇总
    4. 同业对比（3-5 家可比公司）
    5. 估值分析（PE/PB/DCF，给出合理估值区间）
    6. 风险提示
  - 输出结构化研报，支持 PDF 导出
  - 研究过程实时展示进度（AG-UI 流式）
- **数据需求**：
  - 公司财务数据（财报、年报）
  - 行业数据
  - 新闻和研报数据
  - 同业公司数据
- **验收标准**：
  - 研究任务完成时间 ≤ 5 分钟
  - 研报包含上述 6 个模块
  - 研报可导出为 PDF
  - 用户可追问研报中的任何部分
  - 数据来源在研报中明确标注

### R5: 持仓导入与管理

- **用户故事**：作为投资者，我希望导入我的持仓数据，自动计算组合表现和风险指标。
- **功能行为**：
  - 支持 CSV 导入（字段：标的代码、名称、数量、成本价、买入日期）
  - 支持手动逐条录入
  - Agent 自动匹配标的并拉取最新行情
  - 计算：当前市值、盈亏、资产配置分布、行业集中度、年化收益 vs 基准
  - 支持多个组合（如"长期价值"、"短线交易"）
- **数据需求**：
  - 用户持仓数据
  - 行情数据
  - 基准指数数据（沪深 300、标普 500 等）
- **验收标准**：
  - CSV 导入成功率 ≥ 99%（格式正确时）
  - 组合数据实时更新（行情变动后 ≤ 1 分钟）
  - 风险指标计算准确（与主流工具一致）
  - 支持至少 50 个持仓/组合

### R6: 投资笔记与论点追踪

- **用户故事**：作为投资者，我希望记录每笔投资的买入理由和论点，并定期收到 Agent 的论点检验提醒。
- **功能行为**：
  - 在标的详情页或对话中记录笔记
  - 笔记类型：买入理由、卖出理由、研究心得、论点
  - 笔记自动关联到标的
  - Agent 每周自动检验活跃论点（基于最新信息）
  - 论点状态：成立 / 待验证 / 不成立 / 已过期
  - 用户可查看"论点追踪"面板
- **数据需求**：
  - 用户笔记数据
  - 标的最新动态（新闻、公告、行情）
- **验收标准**：
  - 笔记创建后即时保存并关联标的
  - 每周论点检验报告在用户打开应用时展示
  - 论点状态变更时推送通知
  - 支持笔记搜索和筛选

## 9. Data and Permission Requirements

```

PriceAlert {
  id: UUID
```

## 10. Acceptance Criteria

### 10.1 Happy Path

- [ ] 用户打开应用，首页展示今日市场简报卡片，点击展开查看完整简报
- [ ] 用户输入"研究一下比亚迪"，Agent 在 5 分钟内输出完整研报，包含 6 个模块
- [ ] 用户创建观察列表"新能源"，添加宁德时代、比亚迪，列表中展示最新行情
- [ ] 用户导入持仓 CSV，组合面板展示资产配置和收益数据
- [ ] 用户记录买入理由笔记，笔记关联到标的并出现在论点追踪面板

### 10.2 Error Path

- [ ] 行情数据源不可用时，展示降级提示并允许手动刷新
- [ ] 深度研究任务失败时，保留已完成的中间步骤，允许重试
- [ ] CSV 导入格式错误时，明确提示错误字段并给出模板下载
- [ ] 推送服务故障时，异动数据保留在观察列表中，不丢失

### 10.3 Edge Cases

- [ ] 标的代码在多个市场存在（如"AAPL"在 US 和 HK 都有上市），Agent 询问用户确认
- [ ] 用户观察列表超过 100 个标的，分页加载不影响性能
- [ ] 用户同时管理多个组合，切换组合时数据不混淆
- [ ] 论点检验时标的已退市或停牌，标记论点为"已过期"并说明原因

## 12. Risks and Open Questions

### 12.1 风险

| 风险                          | 影响 | 缓解措施                                                              |
| ----------------------------- | ---- | --------------------------------------------------------------------- |
| 行情数据源不稳定或收费        | 高   | 评估多个数据源（Yahoo Finance、Alpha Vantage、Tushare），准备降级方案 |
| 深度研究质量不达标            | 中   | 引入用户评分机制，持续优化 Prompt 和数据源                            |
| 用户将 Agent 输出当作投资建议 | 高   | UI 明确声明"不构成投资建议"，研报中添加免责声明                       |
| 数据抓取触发反爬机制          | 中   | 控制抓取频率，优先使用官方 API                                        |
| 用户数据隐私泄露              | 高   | 严格遵循现有 Supabase RLS，持仓数据加密存储                           |

### 12.2 Open Questions

- [ ] 行情数据源选择：免费（延迟 15 分钟）vs 付费（实时）？需要用户选择还是统一？
- [ ] 深度研究的同业对比逻辑：如何自动选择可比公司？基于行业分类还是人工标注？
- [ ] 估值模型选择：是否支持用户自定义 DCF 假设（增长率、折现率）？
- [ ] 推送通道：是否支持邮件/短信推送，还是仅限应用内推送？
- [ ] 多语言支持：研报是否支持中英文双语生成？
