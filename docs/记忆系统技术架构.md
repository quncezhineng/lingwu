# 技术架构 — LingWu 多 Agent 记忆系统

> 关联 PRD：`docs/PRD-多Agent记忆系统.md` ｜ 本文给出**可直接落地**的架构与精确对接点。
> **记忆引擎**：接入 [Vectorize Hindsight](https://hindsight.vectorize.io/)（`retain`/`recall`/`reflect`），而非自建 embedding + pgvector。

## 0. 已确认的三大技术决策

| # | 决策项      | 结论                                                            |
| - | -------- | ------------------------------------------------------------- |
| 1 | 投研/投融资沉淀 | **模型主动调用** **`write_memory`** **+ 投研信号规则兜底**（评级/目标价/仓位/投融资阶段，双保险）              |
| 2 | 记忆引擎     | **Vectorize Hindsight**（Cloud 或自托管 Docker），bank 隔离 = Agent 隔离 |
| 3 | 存量数据规模   | **\~1 GB**，迁移必须**分批 + 幂等 + 可断点续传**，不能一次性全量                    |

## 3. Hindsight 接入方案

### 3.1 为什么选 Hindsight（而非自建 embedding）

| 需求        | 自建 embedding + pgvector   | Hindsight            |
| --------- | ------------------------- | -------------------- |
| 语义召回      | 需自己写 embedding + 向量库 + 融合 | 内置四路检索（语义/BM25/图/时间） |
| 事实抽取/去重   | 全要手写                      | 内置事实抽取、实体链接、观察合并     |
| "换一种说法"召回 | 需调 embedding 参数           | 原生语义检索 + 图推理         |
| 冲突检测      | 手写                        | 内置（保留新旧状态 + 时间戳）     |
| 维护成本      | 高                         | 低（托管或一行 Docker）      |

### 3.2 部署形态

### 3.3 核心 API（三方法）

```
retain(bank_id, content)   # 写入：抽取事实、实体链接、构图
recall(bank_id, query)     # 召回：四路并行检索 + 交叉编码重排 + token 预算裁剪
reflect(bank_id, query)    # 推理：基于 mission/directives/disposition 生成回答（带引用）
```

## 5. 核心实现点

### 5.1 `agentIdForThread()`（`agent-space.ts`）

```ts
export async function agentIdForThread(
  db: { get: <T>(owner: string, kind: string, id: string) => Promise<T | null> },
  owner: string,
  threadId?: string | null,
): Promise<string | undefined> {
  const id = threadId?.trim();
  if (!id) return undefined;
  const saved = await db.get<PersistedAgentSpace & { id: string }>(
    owner, "agent-settings", "space",
  );
  return saved?.agents.find((agent) => agent.threadId === id)?.id;
}
```

### 5.2 写入：`remember_fact` → 绑定 agentId + 双写（`conversation.ts:477`）

```ts
execute: async ({ text, category }) => {
  const agentId = (await agentIdForThread(this.service.db, this.owner, input.threadId)) ?? "default";
  const value: AgentMemoryV2 = {
    id: createHash("sha256").update(key("memory", agentId, text)).digest("hex"),
    agentId,
    kind: "fact",
    text,
    source: "User confirmed in chat",
    tags: category ? [category] : [],
    createdAt: new Date().toISOString(),
  };
  await this.service.db.insertIfAbsent(this.owner, "memories", value);   // 权威存储
  await this.service.memory.hindsight.retain(this.owner, agentId, text); // 记忆引擎（fire-and-forget 可异步）
  return value;
},
```

### 5.3 召回：`recall_memory` → 语义优先，关键词兜底（`conversation.ts:496`）

```ts
execute: async ({ query, limit }) => {
  const agentId = (await agentIdForThread(this.service.db, this.owner, input.threadId)) ?? "default";
  // 1) 语义召回（Hindsight recall）
  const hits = await this.service.memory.hindsight.recall(this.owner, agentId, query);
  // 2) 关键词兜底（现有 recallMemories，失败或空时启用）
  const mine = (await this.service.db.list<AgentMemoryV2>(this.owner, "memories"))
    .filter((m) => (m.agentId ?? "default") === agentId);
  const fallback = recallMemories(mine, query, limit);
  // 3) 合并：Hindsight 命中优先，去重，回 records 取完整元数据
  return { query, memories: mergeHits(hits, fallback, limit) };
},
```

### 5.4 投研/投融资记忆自动沉淀（模型主动 + 规则兜底）

**模型主动**：在系统提示中新增投研指令，让 Agent 识别到**评级观点 / 目标价 / 交易操作 / 投融资决策**信号时，主动调用 `write_memory`（携带 `financeTerms` / `dealHabits`）。

**规则兜底**（`apps/server/src/engine/deal-signal.ts`，新增，三组信号表覆盖模型漏判）：


投研任务 `succeeded` / 对话回合结束时，扫描最新文本：命中评级 → 落 `thesis`；命中操作词 → 落 `trade`；命中投融资阶段 → 落 `decision`；模型已主动写过的（幂等 id 相同）自动跳过。

## 7. 存量迁移方案（\~1 GB，重点）

**原则：分批 + 幂等 + 断点续传 + 不阻塞服务。**

```
migrate(owner):
  cursor = 读取上次进度（存 records 的 "memory-migration" 记录）
  while 有剩余:
    batch = db.list 按 (agentId, createdAt) 分页取 N=500 条
    for each memory in batch:
      if 已迁移(有 hindsight 映射标记) → skip
      hindsight.retain(bank, memory.text)        # 幂等
      db.put 迁移标记 memory.hindsightMigratedAt
    更新 cursor 进度
    若单批耗时超阈值 → 暂停，等下一 tick 继续
```
