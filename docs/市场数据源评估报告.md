# 行情数据源评估报告

**评估日期**: 2026-10-26  
**评估目标**: 为 LingWu 个人投研智能体 P0 功能选择合适的市场数据 API

---

## 一、数据源对比分析

### 1.1 美股数据源

#### Yahoo Finance API

**优势**:

- ✅ 完全免费，无需 API Key
- ✅ 数据覆盖全面（美股、ETF、指数、加密货币）
- ✅ 实时性好（延迟 15 分钟，符合 P0 要求）
- ✅ 支持历史数据、财务报表、公司信息
- ✅ 社区活跃，有成熟的开源库（yfinance Python, yahoo-finance2 Node.js）

**劣势**:

- ❌ 非官方 API，可能存在稳定性风险
- ❌ 无 SLA 保证
- ❌ 高频请求可能被限流

**Rate Limit**: 无官方限制，建议控制在 2000 次/小时以内  
**数据延迟**: 15 分钟（符合 P0 需求）  
**推荐度**: ⭐⭐⭐⭐⭐

#### Alpha Vantage

**优势**:

- ✅ 官方 API，稳定性有保障
- ✅ 提供技术指标（RSI, MACD, 布林带等）
- ✅ 支持外汇、加密货币

**劣势**:

- ❌ 免费 tier 限制严格：5 次/分钟，500 次/天
- ❌ 需要注册 API Key
- ❌ 数据覆盖不如 Yahoo Finance 全面

**Rate Limit**: 5 次/分钟（免费），25 次/分钟（付费 $49.99/月）  
**数据延迟**: 实时（盘中）  
**推荐度**: ⭐⭐⭐（作为备用）

### 1.2 A 股数据源

#### Tushare

**优势**:

- ✅ 数据质量高，覆盖全面（A 股、基金、期货、宏观）
- ✅ 提供财务数据、公告、股东信息
- ✅ 社区活跃，文档完善
- ✅ 支持 Python SDK

**劣势**:

- ❌ 需要注册获取 token
- ❌ 免费积分有限（基础数据免费，高级数据需要积分）
- ❌ 高频接口需要较高积分

**Rate Limit**: 根据积分等级不同，基础接口 200 次/分钟  
**数据延迟**: 实时（盘中）  
**推荐度**: ⭐⭐⭐⭐

#### AKShare

**优势**:

- ✅ 完全免费，开源项目
- ✅ 无需注册，开箱即用
- ✅ 数据来源多样（东方财富、新浪财经、同花顺等）
- ✅ 覆盖 A 股、基金、期货、宏观经济

**劣势**:

- ❌ 依赖爬虫，稳定性受数据源网站影响
- ❌ 接口可能因数据源网站变化而失效
- ❌ 无官方 SLA

**Rate Limit**: 无官方限制，建议控制在 1000 次/小时以内  
**数据延迟**: 实时（盘中）  
**推荐度**: ⭐⭐⭐⭐⭐

### 1.3 港股数据源

#### 富途 OpenAPI

**优势**:

- ✅ 官方 API，数据质量高
- ✅ 实时行情（需开户）
- ✅ 支持交易功能（未来扩展）

**劣势**:

- ❌ 需要富途账户
- ❌ 免费 tier 有限
- ❌ 申请流程复杂

**推荐度**: ⭐⭐⭐（P2 阶段考虑）

#### 新浪财经港股接口

**优势**:

- ✅ 免费，无需注册
- ✅ 数据覆盖港股

**劣势**:

- ❌ 非官方接口，稳定性无保证
- ❌ 数据延迟较大（30 分钟以上）

**推荐度**: ⭐⭐（作为备用）

## 二、推荐方案

### 2.1 P0 阶段推荐组合

**美股**: Yahoo Finance API  
**理由**: 免费、数据全面、社区支持好，15 分钟延迟满足 P0 需求

**A 股**: AKShare  
**理由**: 完全免费、无需注册、开箱即用，数据来源多样

**港股**: 暂不接入（P0 聚焦美股和 A 股）  
**理由**: 免费数据源质量不稳定，建议 P1 阶段评估富途 OpenAPI

### 2.2 备选方案

**美股备选**: Alpha Vantage（免费 tier 作为降级方案）  
**A 股备选**: Tushare（需要用户自行注册 token）

### 2.3 技术选型

**Node.js 库推荐**:

- 美股: `yahoo-finance2` (npm 包，TypeScript 支持好)
- A 股: 直接调用 AKShare HTTP 接口或使用 `akshare` Python 包（通过 Linux 沙箱）

**实现策略**:

1. 优先使用 Node.js 原生实现（美股 Yahoo Finance）
2. A 股数据通过 Linux 沙箱调用 AKShare Python 脚本
3. 统一封装为 `MarketDataProvider` 接口，支持多数据源切换

## 三、风险评估

### 3.1 数据源稳定性风险

**风险**: Yahoo Finance 和 AKShare 都是非官方接口，可能因上游变化而失效  
**缓解措施**:

- 实现多数据源降级机制
- 缓存最近一次成功的数据（TTL 5 分钟）
- 监控 API 调用成功率，低于 95% 触发告警
- 前端展示"数据延迟"提示

### 3.2 Rate Limit 风险

**风险**: 高频请求可能被数据源限流  
**缓解措施**:

- 实现请求队列和限流器
- 行情数据缓存 1 分钟（符合 P0 延迟要求）
- 批量查询优化（一次请求多个标的）
- 用户级别限流（每用户每分钟最多 10 次查询）

### 3.3 数据准确性风险

**风险**: 非官方数据源可能存在数据错误  
**缓解措施**:

- 数据校验（价格范围、涨跌幅合理性检查）
- 交叉验证（关键数据从多个源验证）
- 用户反馈机制（标记异常数据）
