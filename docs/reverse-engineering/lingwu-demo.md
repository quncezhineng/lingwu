## 已观察事实

### 信息架构

桌面主导航为：工作台、我的自选、分析任务、我的资料、盯盘与提醒、投资偏好、数据连接。侧栏还承载“最近的分析”、助手状态和个人空间。移动端只保留工作台、自选、分析任务、盯盘、我的五个入口。

### 侧栏底部

- `div#app > aside.sidebar > .sidebar-bottom` 内是助手状态和个人空间两个独立区域，不是同一条导航。
- 助手状态由头像、名称、蓝色状态点、实时盯盘数量和设置图标组成；数量直接读取启用的 routines，而不是分析任务数。
- 个人空间入口显示用户头像、姓名和“个人空间”，整行可点击；LingWu 还保留独立齿轮设置入口，避免账户与全局设置混在一起。
- Demo 使用约 30px 圆形头像、10–12px 两级文字和 1px 顶部分隔线；LingWu 保留 44px 级触控热区，并在无真实头像时回退到姓名首字母。

### 工作台

- 日期眉题 + 衬线问候。
- 大尺寸自然语言分析框，带附件区、多行输入、资料上传、资料库、深度分析入口和圆形发送按钮。
- 右侧信息轨依次是自选行情、待确认提醒、投资偏好摘录和隐私说明。
- 主区下方是今日领悟卡与进行中的分析任务。
- 今日市场简报是独立入口，不与任务列表混排。

### 对话输入区

- 工作台 `hero-composer` 与任务对话 `chat-composer` 共用 `app.js` 中的同一套 `composer()` 结构。
- 输入区为白底、1px 描边、14px 圆角；聚焦时使用弱蓝灰描边和极轻阴影。
- 底栏左侧依次为上传、资料库、语音和分隔线，随后是“状态点 + 深度分析 + 下拉箭头”，右侧是圆形发送按钮。
- 附件作为输入区上方的胶囊列表展示，可单独移除。
- “从我的资料选择”（`app.js:76`）打开“选择我的资料”弹层（`materials.js:151`）。弹层支持多选资料、显示已选数量，并提供“上传资料”和“加入对话”动作；确认后只在输入区恢复/生成文本，不因弹层交互丢失已有草稿。
- 若确认时输入区为空，Demo 自动填入“请结合这些资料，整理核心观点、关键数据和需要进一步核验的问题。”（`materials.js:66-71`）。附件随工作台分析或对话消息一起发送。
- Demo 资料库支持 PDF、HTML、Word、Markdown、图片、文本与 CSV；LingWu 后端当前仅接受 PDF/HTML，因此迁移后的选择器只展示并导入这两类真实支持的文件，空状态明确提示格式边界。
- “深度分析”的源码动作实际打开的是投资助理说明弹层，不是分析档位选择器；因此 LingWu 将它映射为真实存在的智能体设置入口，避免伪造尚不存在的模型档位参数。

### 今日市场简报

- 入口位于工作台问候区右侧，点击打开约 760px 宽的独立弹层。
- 弹层结构：日期与“收盘摘要”上下文、来源标记、一句话导读、三项指数摘要、今日领悟阅读线索、可折叠完整简报、底部下载与继续分析动作。
- 指数摘要使用三列细线分隔；中国市场沿用红涨绿跌。
- 阅读线索是紧凑领悟卡，显示分类、标题、标的信息和“展开看看”，点击进入完整领悟内容。
- 完整简报依次覆盖“今日市场一览”“股票与基金关注”“与你的自选有什么关系”“下一步关注什么”。
- 底部动作将简报导出为资料，或把简报上下文带入新一轮分析。

### 我的自选

- 页头由“我的自选”、说明文字和“添加自选”主操作组成，筛选控件置于标题下方。
- 市场分组为全部、A股、港股、美股、基金；基金分组同时收纳 ETF 和场外基金。
- “已关注 N 个标的”展示当前数量，旁边明确标注行情来源；桌面端使用六列表格，依次为名称/代码、市场/类型、最新价/净值、涨跌幅、近月走势和操作。
- 名称或代码可即时筛选当前列表；添加动作使用独立弹窗，弹窗内再提供搜索和市场分组，并始终添加到当前观察列表。
- 桌面行内提供“分析”和删除；移动端卡片保留详情、分析和更多操作。删除后应可撤销，避免误操作直接丢失关注项。
- Demo 使用示例行情；落库到 LingWu 时必须保持真实行情、加载失败和空走势的明确状态，不能为缺失数据合成曲线或净值。

### 分析路径

自然语言请求会进入分析任务；任务展示计划、过程、证据、待确认状态和最终资料。资料可继续投入对话，分析结果可沉淀到资料库。自选行情可进入详情、继续分析或设置提醒。

### 视觉系统

- 页面 `#f8f8f8`，侧栏 `#f4f4f4`，白纸卡片 `#ffffff`。
- 正文 `#303030`，次级文字 `#808080`，描边 `#e6e6e6`。
- 品牌蓝 `#3a83f7`，浅蓝选中面 `#edf3ff`，深蓝操作色 `#2f6fd8`。
- 行情红涨 `#c4384b`、绿跌 `#217d62`。
- 1px 描边分层、弱阴影；圆角约 7–14px。
- 问候和领悟标题使用 Noto Serif SC / Songti 一类衬线字体，导航和正文使用 Noto Sans SC / PingFang。

## 信息架构调整

- `我的自选` 不再出现在「数据连接 → 在你的电脑上」，仅保留侧栏和移动端主入口。
- `我的资料` 不再出现在「数据连接 → 在你的电脑上」，仅保留侧栏和移动端入口。
- `智能体电脑` 不再作为数据连接页的电脑快捷入口，保留对话内入口。
- `投资组合` 不再出现在「数据连接 → 在你的电脑上」，统一从「我的自选」进入。
- `投资笔记` 不再出现在「数据连接 → 在你的电脑上」，统一从「我的资料」进入。
- 语言切换只保留在顶部栏，左侧栏底部不再重复展示。
- 桌面顶部原会话菜单入口改为全局搜索，覆盖分析任务、研究资料、文件、会话、邮件、日历、投资偏好和盯盘提醒。
- 桌面侧栏恢复「对话」入口；进入对话后重新显示历史会话列表栏，可切换、新建、重命名和归档会话。
- 侧栏和页面标题「数据连接」更名为「应用与资源」，页面按插件、技能、连接器重新组织；搜索与分类筛选覆盖各类能力。
- 「知识库」统一更名为「资料库」。
- 「邮件」「日历」作为工作区应用保留在能力列表中，并排在外部连接器之前，避免把本地入口与第三方连接混为一类。
- 「我的」页面不再重复放置资料、偏好、应用和盯盘快捷入口，侧栏已经承载这些一级导航。
- 二级页面保留父级面包屑和返回按钮；侧栏分别高亮「投资偏好」和「我的资料」，避免误高亮「分析任务」。

## 实现选择与未知项

- Demo 的行情、资料与任务均为静态演示数据；lingwu 接入现有真实 API，空数据时呈现明确空状态，不编造结论。
- Demo 的“小悟”头像、四瓣花标识和部分插画属于静态资产；当前实现使用轻量四瓣花品牌符号和既有头像资产。
- Demo 的语音输入、附件拖入和 Word 本地解析未在本轮界面迁移中新增；现有对话附件与资料库能力保留。“从我的资料选择”已迁移为真实文件选择与附件发送流程。
- Demo 的“深度分析”标签未提供真实分析档位切换；“深度分析”入口在 LingWu 中连接到智能体个性与记忆设置，实际分析行为继续由现有提示词、模型和工具链决定。
- `FUND` 是前端市场分组类型，现有后端证券 schema 仍只接受 `US | CN | HK`；添加基金时沿用代码目录和人民币映射，不向服务端发送不支持的 `market: "FUND"`。
- Demo 支持手动录入任意证券；LingWu 当前没有对应的自定义证券持久化能力，因此只提供真实目录与搜索接口返回的标的。基金行情或 `sparkline` 缺失时展示“暂无行情 / 暂无走势”，不做金融数据合成。
- 响应式断点按 1440px 桌面和常见移动宽度设计；平板中间宽度的最佳密度仍需实机走查。
