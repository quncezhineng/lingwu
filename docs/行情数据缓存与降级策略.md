## 一、缓存策略

### 1.1 缓存层级架构

```
┌─────────────────────────────────────────────────────┐
│  L1: 内存缓存 (LRU Cache)                           │
│  - TTL: 60 秒                                       │
│  - 容量: 10,000 个标的                               │
│  - 用途: 高频实时行情查询                              │
├─────────────────────────────────────────────────────┤
│  L2: 磁盘缓存 (JSON 文件)                            │
│  - TTL: 5 分钟 (新鲜数据)                             │
│  - TTL: 30 分钟 (降级数据)                            │
│  - 用途: 进程重启后恢复、降级回退                        │
├─────────────────────────────────────────────────────┤
│  L3: 数据库缓存 (PostgreSQL JSONB)                   │
│  - TTL: 1 小时 (历史快照)                              │
│  - 用途: 历史数据查询、报表生成                          │
└─────────────────────────────────────────────────────┘
```

### 1.3 缓存更新策略

**写策略**: Cache-Aside (旁路缓存)

```typescript
async function getQuote(symbol: string): Promise<Quote> {
  // 1. 查询 L1 内存缓存
  const cached = lruCache.get(`market:${symbol}:quote`);
  if (cached && !isExpired(cached, 60_000)) {
    return cached.data;
  }

  // 2. 查询 L2 磁盘缓存
  const diskCached = await readDiskCache(`market:${symbol}:quote`);
  if (diskCached && !isExpired(diskCached, 300_000)) {
    lruCache.set(`market:${symbol}:quote`, diskCached); // 回填 L1
    return diskCached.data;
  }

  // 3. 调用 API 获取最新数据
  try {
    const fresh = await fetchFromAPI(symbol);
    const entry = { data: fresh, timestamp: Date.now() };
    lruCache.set(`market:${symbol}:quote`, entry);
    await writeDiskCache(`market:${symbol}:quote`, entry);
    return fresh;
  } catch (error) {
    // 4. 降级: 返回过期缓存
    if (diskCached) {
      logger.warn(`Returning stale cache for ${symbol}`, { error });
      return diskCached.data;
    }
    throw error;
  }
}
```

**批量查询优化**:

```typescript
// 支持一次查询多个标的，减少 API 调用次数
async function getQuotes(symbols: string[]): Promise<Map<string, Quote>> {
  const results = new Map<string, Quote>();
  const uncached: string[] = [];

  // 1. 批量查询缓存
  for (const symbol of symbols) {
    const cached = lruCache.get(`market:${symbol}:quote`);
    if (cached && !isExpired(cached, 60_000)) {
      results.set(symbol, cached.data);
    } else {
      uncached.push(symbol);
    }
  }

  // 2. 批量查询 API (每次最多 50 个)
  if (uncached.length > 0) {
    const batches = chunk(uncached, 50);
    for (const batch of batches) {
      const fresh = await fetchBatchFromAPI(batch);
      for (const [symbol, quote] of fresh) {
        const entry = { data: quote, timestamp: Date.now() };
        lruCache.set(`market:${symbol}:quote`, entry);
        results.set(symbol, quote);
      }
    }
  }

  return results;
}
```

### 1.4 缓存失效策略

**主动失效**:
- 用户手动刷新（前端触发 `forceRefresh` 参数）
- 标的发生重大事件（财报发布、分红除权）
- 数据源切换（Yahoo Finance → Alpha Vantage）

**被动失效**:
- TTL 过期（60 秒）
- LRU 淘汰（容量超 10,000）
- 磁盘空间不足（保留最近 7 天）

### 1.5 缓存预热

**启动时预热**:
```typescript
async function warmupCache(): Promise<void> {
  // 1. 加载所有活跃用户的观察列表标的
  const watchlists = await loadAllActiveWatchlists();
  const symbols = new Set<string>();
  for (const wl of watchlists) {
    for (const symbol of wl.symbols) {
      symbols.add(symbol);
    }
  }

  // 2. 批量预加载行情数据
  const quotes = await getQuotes(Array.from(symbols));
  logger.info(`Cache warmed up with ${quotes.size} symbols`);
}
```

**定时预热**:
```typescript
// 每日市场简报生成前 10 分钟预热
cron.schedule('50 23 * * *', async () => {
  await warmupCache();
  logger.info('Cache warmed up for daily briefing');
});
```

## 二、降级策略

### 2.1 降级层级

```
┌──────────────────────────────────────────────────────┐
│  Level 0: 正常模式                                    │
│  - 数据源: Yahoo Finance / AKShare                    │
│  - 延迟: ≤ 15 分钟 (美股) / ≤ 1 分钟 (A股)             │
│  - 成功率: ≥ 95%                                      │
├──────────────────────────────────────────────────────┤
│  Level 1: 备用数据源模式                               │
│  - 触发条件: 主数据源连续 3 次失败                       │
│  - 数据源: Alpha Vantage (美股) / Tushare (A股)         │
│  - 延迟: 可能增加 5-10 分钟                             │
│  - 自动恢复: 主数据源连续 5 次成功后切回                  │
├──────────────────────────────────────────────────────┤
│  Level 2: 缓存降级模式                                 │
│  - 触发条件: 所有数据源不可用                            │
│  - 数据源: 返回过期缓存（标记"数据延迟"）                 │
│  - 延迟: 可能超过 5 分钟                                 │
│  - 前端提示: 显示"数据更新延迟，请稍后刷新"               │
├──────────────────────────────────────────────────────┤
│  Level 3: 只读模式                                     │
│  - 触发条件: 缓存也过期（超过 30 分钟）                   │
│  - 行为: 禁止查询，返回错误提示                           │
│  - 前端提示: "行情数据暂时不可用，请稍后再试"              │
└──────────────────────────────────────────────────────┘
```

```typescript
interface DegradationConfig {

  primaryFailureThreshold: 3;      // 连续 3 次失败触发降级

  staleCacheTTL: 300_000;          // 30 分钟内可返回过期缓存
  readOnlyTTL: 1_800_000;          // 超过 30 分钟进入只读模式
  
  // 超时配置
  apiTimeout: 10_000;              // API 请求超时 10 秒
  cacheLookupTimeout: 100;         // 缓存查询超时 100ms
}
```

### 2.3 降级实现

```typescript
class MarketDataProvider {
  private primarySource: DataSource;
  private backupSource: DataSource;
  private failureCount = 0;
  private successCount = 0;
  private mode: 'normal' | 'backup' | 'cache' | 'readonly' = 'normal';

  async getQuote(symbol: string): Promise<Quote> {
    // Level 0: 正常模式
    if (this.mode === 'normal') {
      try {
        const quote = await this.primarySource.getQuote(symbol);
        this.onPrimarySuccess();
        return quote;
      } catch (error) {
        this.onPrimaryFailure(error);
        return this.getQuoteWithFallback(symbol);
      }
    }

    // Level 1: 备用数据源模式
    if (this.mode === 'backup') {
      try {
        const quote = await this.backupSource.getQuote(symbol);
        this.onPrimarySuccess(); // 尝试恢复主数据源
        return quote;
      } catch (error) {
        logger.error('Backup source failed', { symbol, error });
        return this.getCachedQuote(symbol);
      }
    }

    // Level 2: 缓存降级模式
    if (this.mode === 'cache') {
      return this.getCachedQuote(symbol);
    }

    // Level 3: 只读模式
    throw new MarketDataUnavailableError('行情数据暂时不可用');
  }

  private onPrimarySuccess(): void {
    this.failureCount = 0;
    this.successCount++;
    if (this.mode === 'backup' && this.successCount >= 5) {
      logger.info('Switching back to primary data source');
      this.mode = 'normal';
      this.successCount = 0;
    }
  }

  private onPrimaryFailure(error: Error): void {
    this.successCount = 0;
    this.failureCount++;
    logger.error('Primary data source failed', { 
      failureCount: this.failureCount, 
      error: error.message 
    });
    
    if (this.failureCount >= 3 && this.mode === 'normal') {
      logger.warn('Switching to backup data source');
      this.mode = 'backup';
      this.failureCount = 0;
    }
  }

  private async getCachedQuote(symbol: string): Promise<Quote> {
    const cached = await readDiskCache(`market:${symbol}:quote`);
    if (!cached) {
      this.mode = 'readonly';
      throw new MarketDataUnavailableError('No cached data available');
    }

    const age = Date.now() - cached.timestamp;
    if (age > 1_800_000) { // 30 分钟
      this.mode = 'readonly';
      throw new MarketDataUnavailableError('Cache expired');
    }

    // 标记为延迟数据
    return {
      ...cached.data,
      _degraded: true,
      _cacheAge: age,
      _message: age > 300_000 ? '数据更新延迟，请稍后刷新' : undefined,
    };
  }
}
```

## 三、限流策略

### 3.1 用户级限流

```typescript
// 每用户每分钟最多 60 次查询
const userRateLimiter = rateLimit({
  windowMs: 60_000,
  max: 60,
  keyGenerator: (req) => req.user.id,
  message: '查询频率过高，请稍后再试',
});
```

### 3.2 API 级限流

```typescript
// Yahoo Finance: 2000 次/小时
// AKShare: 1000 次/小时
// Alpha Vantage: 5 次/分钟（免费）
const apiRateLimiter = new RateLimiter({
  'yahoo-finance': { windowMs: 3_600_000, max: 2000 },
  'akshare': { windowMs: 3_600_000, max: 1000 },
  'alpha-vantage': { windowMs: 60_000, max: 5 },
});
```

### 3.3 批量查询优化

```typescript
// 将多个单查询合并为批量查询
async function batchQueries(queries: Query[]): Promise<Result[]> {
  const batches = chunk(queries, 50); // 每批最多 50 个
  const results: Result[] = [];
  
  for (const batch of batches) {
    await apiRateLimiter.wait('yahoo-finance'); // 等待限流
    const batchResult = await fetchBatch(batch);
    results.push(...batchResult);
  }
  
  return results;
}
```

## 四、监控与告警

### 4.1 监控指标

```typescript
interface MarketDataMetrics {
  // API 调用指标
  apiCallsTotal: Counter;           // 总调用次数
  apiCallDuration: Histogram;       // 调用耗时分布
  apiCallErrors: Counter;           // 错误次数（按类型分组）
  
  // 缓存指标
  cacheHits: Counter;               // 缓存命中次数
  cacheMisses: Counter;             // 缓存未命中次数
  cacheHitRate: Gauge;              // 缓存命中率
  
  // 降级指标
  degradationLevel: Gauge;          // 当前降级级别 (0-3)
  degradedRequests: Counter;        // 降级请求次数
  
  // 数据质量指标
  staleDataReturned: Counter;       // 返回过期数据次数
  dataValidationErrors: Counter;    // 数据校验失败次数
}
```

### 4.2 告警规则

```yaml
# Prometheus 告警规则
groups:
  - name: market-data
    rules:
      - alert: MarketDataAPIHighErrorRate
        expr: rate(apiCallErrors[5m]) / rate(apiCallsTotal[5m]) > 0.05
        for: 5m
        labels:
          severity: warning
        annotations:
          summary: "行情数据 API 错误率超过 5%"
          
      - alert: MarketDataCacheHitRateLow
        expr: cacheHitRate < 0.8
        for: 10m
        labels:
          severity: warning
        annotations:
          summary: "行情数据缓存命中率低于 80%"
          
      - alert: MarketDataDegradationActive
        expr: degradationLevel > 0
        for: 2m
        labels:
          severity: critical
        annotations:
          summary: "行情数据降级模式已激活 (Level {{ $value }})"
          
      - alert: MarketDataAPILatencyHigh
        expr: histogram_quantile(0.95, apiCallDuration) > 5
        for: 5m
        labels:
          severity: warning
        annotations:
          summary: "行情数据 API 95 分位延迟超过 5 秒"
```
